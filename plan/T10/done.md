Delivered: `scull-ffi` exports a hand-written C ABI (`crates/scull-ffi/include/scull.h`, generated by cbindgen; C# `bindings/csharp/NativeMethods.g.cs`, generated by csbindgen; a drift test with `SCULL_BLESS=1` keeps both current). `tt_abi_version`, `tt_status` codes, `struct_size` first in every struct with append-only fields, `tt_term_new`/`tt_term_spawn` (PTY child), `feed`, non-blocking `write`, `resize_begin`/`resize` (pauses PTY output during a drag, rewraps once, resizes the PTY with pixel sizes), `poll_event` (bell, child exit), `free`, and `tt_frame_new`/`update`/`free` whose view points into the frame's own buffers until the next update. One coalesced wakeup callback per terminal, never called after `free` returns. Every export runs under `catch_unwind`; a panic in a call or on a PTY thread poisons only that terminal (`TT_PANIC`, then `TT_POISONED`; output is drained so the child never stalls). Core additions: `Terminal::resize` and `take_bell` in scull-term, `Pty::pause_output`/`resume_output` and `Sink::wants_wakeup`/`deadline` in scull-pty. `just c-abi-test` runs a two-thread C program (feed and resize on one thread, frame reads on the other) under ASan+UBSan and TSan; both pass on macOS arm64. The Linux CI path is written but has not run yet. Patterns from ketch-capi (guards, drift test) were reused; no code was ported.

Left out: title, clipboard and other OSC events (T13), key and mouse input exports, `scroll_display`, images in the frame (T19.4), palette resolution, `tt_last_error`, and instrumenting the Rust side under sanitizers (needs nightly).
