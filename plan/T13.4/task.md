# T13.4. macOS selection, copy and find UI

macOS selection, copy and search UI over T13.2 (waits for it): mouse drag, double and triple click, Cmd-C, Cmd-F find bar with next and previous. Verify: `just macos-test`, a `-ScullSnapshot` with a selection and a highlighted match.

Plan: `TerminalSession` wraps the select, selection-text and search exports (the selection text shares `readText`'s sized-read loop). `SelectionGesture.swift` holds the pure parts: the pointer-to-cell mapping the mouse path already does, and press decisions (one click a cell, two a word, three a line, Option a block, Shift extends an existing selection). `TerminalView+Selection.swift` runs them: a press goes to the program first, as today, unless Shift forces selection (xterm's convention); a click that did not drag clears; a drag past the top or bottom edge scrolls the history one row per motion event; `copy:` writes the selection text to the pasteboard and is validated off while nothing is selected; a key typed into the terminal clears the selection. `Palette` gains selection (the system accent blended over the background in `Palette(settings)`, as the config has no selection colour), match and current-match colours; `MetalRenderer.build(row:)` picks the cell background by `tt_cell.flags` and draws current-match glyphs dark on their bright background. The core hashes the flags into its row damage, so flag-only changes rebuild just those rows; a renderer test checks that. `FindBar.swift` is a pure `FindState` (open, edit, settle, step, case toggle, close as effects) and a floating top-right bar (`NSSearchField`, a Match Case toggle, previous and next, a "m matches" label; the core does not say which match is current, so no "n of m"); `TerminalView+Find.swift` applies the effects. Typing sets the pattern at once (the frame marks visible matches cheaply) and a 250 ms settle timer then steps to the first match and counts, because step and count rescan the whole history. Return and Cmd-G step forward, Shift-Return and Cmd-Shift-G back, Escape ends the search and returns the keyboard to the terminal. `ScullApp` replaces the Edit menu's text-editing group with Find, Find Next and Find Previous through the responder chain. Debug flags `-ScullFind <pattern>` and `-ScullSelect <row,col,row,col>` mark the frame just before `-ScullSnapshot`. Tests (`SelectionTests.swift`, `FindTests.swift`): gesture mapping, copy text on a named pasteboard, the find state machine, and flag colours in the rendered pixels after a flag-only change.
