Delivered: T14.1 stores mouse tracking (9/1000/1002/1003), mouse encodings (1005/1006/1015/1016), alternate scroll (1007) and a per-screen kitty keyboard flag stack (`CSI > u`, `< u`, `= u`, `? u`) in `scull-term`, which now depends on `scull-input` for the types; DECRQM reports them. `scull-pty` gained `write_input_whole` so an input event is queued whole or not at all. `scull-ffi` ABI 0.3 exports `tt_term_key`, `tt_term_text`, `tt_term_paste`, `tt_term_focus`, `tt_term_mouse` and `tt_term_scroll_display`, encoding against the live modes, plus status `TT_FULL`. T14.2 adds the Swift package `macos/` (`CScull` module over `scull.h`, `ScullKit` with `TerminalSession`, `Palette`, `KeyMap`, `TerminalView` and `TerminalSurface`, and the SwiftUI `Scull` app, macOS 26, arm64 only). The view draws backgrounds and one CoreText `CTLine` per text run (bold, italic, dim, inverse, underline, strike, overline, 256 colours and truecolor, wide cells, block cursor), maps keys, text, mouse, wheel, paste and focus to the exports, holds output during live resize and closes the window when the shell exits. `just macos` builds the static library and assembles an ad-hoc signed `target/macos/Scull.app`; `just macos-test` runs 5 Swift tests. Verified with the app's debug snapshot (`-ScullSnapshot`) after `-ScullInitialInput 'ls -la'`: output, colours, styles, wide characters and the cursor render. The Swift linking setup follows `apps/slint-bindings/swift`; nothing was ported. Both sub-tasks went over the 500-line budget (about 550 and 640 code lines).
